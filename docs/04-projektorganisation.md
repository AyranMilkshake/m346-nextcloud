# 4. Projektorganisation

Zur Verfügung stehen 3 × 2 Lektionen im Unterricht.

## 4.1 Aufgabenverteilung

| Bereich | Verantwortlich | Weitere Beteiligte (Review) |
|---|---|---|
| DB-Server: `install-db.sh`, Firewall, Root-Absicherung | `[Name A]` | `[Name B]` |
| Web-Server: `install-web.sh`, Apache, PHP, Nextcloud | `[Name B]` | `[Name C]` |
| Automatisierung: `render.sh`, Cloud-Init, Cloud-Setup (Netz, Security Groups) | `[Name C]` | `[Name A]` |
| Doku: README, Architektur, Inbetriebnahme | `[Name C]` | `[Name A]` |
| Tests und Testprotokoll | `[Name A]` | `[Name B]` |
| Git-Verwaltung: Branch-Schutz, Pull-Request-Regeln, Lehrperson einladen | `[Name B]` | alle |

## 4.2 Zeitplan

| Termin | Ziele |
|---|---|
| Lektion 1-2 | Gruppe bilden, Repo anlegen (alle + Lehrperson eingeladen), Cloud-Zugang, Netz planen, Skripte entwerfen |
| Lektion 3-4 | Skripte fertigstellen, erste vollständige Bereitstellung in der Cloud, Fehler beheben |
| Lektion 5-6 | Tests mit Screenshots, Doku fertigstellen, Review aller Pull Requests, Abgabe prüfen |

## 4.3 Kommunikation mit der Lehrperson

Bei Blockaden (z. B. Cloud-Zugang, Netzwerkprobleme) wird die Lehrperson **am gleichen Tag** informiert und nicht erst am Ende der Lektionsreihe.
